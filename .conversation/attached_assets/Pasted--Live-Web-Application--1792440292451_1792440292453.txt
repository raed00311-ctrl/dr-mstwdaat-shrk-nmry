قم بتصميم وتطوير تطبيق ويب متكامل ومربوط أونلاين (Live Web Application) بالكامل لـ "شركة نمري للمقاولات" لإدارة وتتبع المستودعات، المخزون، الصادر والوارد، والمشاريع عبر الإنترنت.

أولاً: معلومات المشرف والبيئة البرمجية والتشغيل (Deployment & Hosting):
1. اسم الشركة الأساسي: "شركة نمري للمقاولات" (يظهر بشكل بارز في أعلى جميع صفحات الموقع).
2. النشر التشغيلي (Online Deployment):
   - إعداد وتهيئة التطبيق كاملاً ليعمل أونلاين على سيرفر Replit عبر رابط ويب حي (Public Web URL).
   - إمكانية الوصول إلى التطبيق وتصفحه من أجهزة الكمبيوتر، الهواتف الذكية، والأجهزة اللوحية دون مشاكل في التنسيق.
3. قاعدة البيانات (Database Management):
   - استخدام قاعدة بيانات حقيقية (مثل SQLite أو PostgreSQL) تعمل بشكل دائم ومستمر.
   - ضمان حفظ البيانات واستمراريتها دون ضياع عند إعادة تشغيل السيرفر.
   - دعم إنشاء نسخ احتياطية (Backups) تلقائية أو إمكانية تنزيل نسخة من قاعدة البيانات.

ثانياً: هيكلية المستودعات والصلاحيات (Warehouse Architecture & Authentication):
1. إدارة المستودعات:
   - المستودع الرئيسي: "المستودع الرئيسي في المفرق" (يكون المستودع الافتراضي لكافة العمليات والتوريدات).
   - المستودع الفرعي: "مستودع الموقع / عمان" (أو أي موقع عمل فرعي تحدده الإدارة).
   - دعم التجميع والربط الشامل بين المستودعين بحيث تتحدث الكميات أوتوماتيكياً في الشاشات.
2. نظام تسجيل الدخول والصلاحيات (User Roles & Access Control):
   - نظام حماية وحسابات يتطلب اسم مستخدم وكلمة مرور.
   - حساب مدير المستودع (Warehouse Manager):
     * الصلاحيات: إضافة مواد جديدة، تعديل بيانات المواد، تسجيل حركات الصادر والوارد، وإجراء عمليات الجرد.
   - حساب المدير العام / الإدارة (Admin / CEO):
     * الصلاحيات: عرض كافة البيانات الإحصائية، متابعة الحركة المالية والكميات، استخراج وتصدير التقارير، دون إمكانية التعديل العشوائي في الكميات.

ثالثاً: إدارة المواد والمخزون الحالية (Inventory System & Catalog):
1. بيانات المواد (Item Master Data):
   - رمز المادة (Item Code / Barcode) مثل: 50117.
   - اسم المادة (Item Name) مثل: حديد مشكل، طوب، جرانيت، مطابخ، مواد بناء.
   - التصنيف الرئيسي (Category) مثل: إنشائيات، تشطيبات، كهرباء، سباكة.
   - وحدة القياس (Unit) مثل: طن، متر مربع، حبة، كيس.
   - المستودع التابع له (الرئيسي بالمفرق أو الفرعي).
   - الكمية الحالية المتوفرة (Current Stock).
   - حد الأمان / الحد الأدنى للمخزون (Minimum Stock Level) لتنبيه إعادة الطلب.
2. إدارة الحركات (Transactions - الصادر والوارد):
   - تسجيل حركات الوارد (Stock-In):
     * إضافة كميات جديدة إلى المستودع الرئيسي بالمفرق عند الشراء أو التوريد.
     * توثيق تاريخ الحركة، اسم المورد، رقم الفاتورة أو الإرسالية، والكمية الموردة.
   - تسجيل حركات الصادر (Stock-Out):
     * صرف كميات من المستودع لصالح مشروع محدد.
     * توثيق اسم المشروع المستلم، تاريخ الصرف، اسم الموظف المستلم، والكمية الصادرة.
     * الخصم التلقائي الفوري من كمية المستودع المعني.

رابعاً: الميزات الذكية والتحليلات (Smart Features & Dashboard):
1. لوحة الإحصائيات التفاعلية (Dashboard & Analytics):
   - بطاقات إحصائية علوية (KPI Cards) تعرض:
     * إجمالي عدد المواد المسجلة في كل مستودع.
     * إجمالي الحركات (الصادر والوارد) التي تمت هذا الشهر.
     * عدد التنبيهات للمواد الناقصة.
     * إجمالي عدد المشاريع النشطة التي تم الصرف لها.
   - رسوم بيانية تفاعلية (Interactive Charts):
     * رسم بياني لإجمالي الصادر والوارد شهرياً.
     * رسم بياني يوضح نسبة توزيع المخزون بين مستودع المفرق والمستودع الفرعي.
2. نظام التنبيهات الآلي (Stock Alert System):
   - تمييز الصفوف والمواد التي وصلت أو قلّت عن حد الأمان باللون الأحمر التنبيهي (Low Stock Badge).
   - شريط تنبيهات علوي يعرض قائمة سريعة بالمواد المطلوبة لإعادة الشراء فوراً قبل نفادها.
3. نظام البحث والفلترة المتقدم (Advanced Search & Filter):
   - شريط بحث فوري للبحث برمز المادة أو اسم المادة.
   - تصفية الجدول بحسب المستودع (المفرق أو الفرعي).
   - تصفية الجدول بحسب التصنيف أو بحسب حركة الصادر والوارد.

خامساً: الواجهات وتجربة المستخدم (UI / UX Design):
1. اللغة والاتجاه:
   - الواجهة بالكامل باللغة العربية مع مراعاة اتجاه الكتابة من اليمين إلى اليسار (RTL).
2. التصميم الفني:
   - تصميم عصري، نظيف، وبسيط باستعمال Bootstrap 5 أو Tailwind CSS.
   - ألوان مريحة للعين تناسب شركات المقاولات (مثل الكحلي، الأزرق، والرمادي العصري).
   - شريط navigation علوي يحتوي على اسم "شركة نمري للمقاولات" مع أزرار التنقل السريعة بين:
     * لوحة التحكم (Dashboard).
     * إدارة المستودعات (Inventory).
     * تسجيل حركة جديدة (New Transaction).
     * سجل الحركات (History Logs).
     * التقارير والتصدير (Reports).
3. تجربة التصفح المترابطة:
   - تصميم متجاوب ليعمل بتناسق تام على هواتف أندرويد وآيفون، والشاشات المختلفة.

سادساً: التقارير وتصدير البيانات (Reports & Data Export):
1. التصدير المباشر:
   - إضافة زر "تصدير إلى Excel" لطباعة أو حفظ كشف المخزون المالي والحالي بضغطة زر.
   - إضافة زر "تصدير سجل الحركات" لإنشاء ملف إكسل يوضح كافة حركات الصادر والوارد مع التواريخ والمشاريع.
2. الطباعة المباشرة (PDF/Print Friendly):
   - إمكانية طباعة سند صرف أو سند استلام مادة بشكل منسق لتقديمه للإدارة.

سابعاً: متطلبات الأكواد البرمجية والتنفيذ:
1. بناء السيرفر بـ Node.js مع مكتبة Express.
2. إعداد المسارات (API Endpoints) الخاصة بالمستودعات، الحركات، والبيانات بشكل منظّم وعصري.
3. بناء قاعدة البيانات بجداول متكاملة ومتسامحة مع الأخطاء.
4. التأكد من خلو المشروع من أي أخطاء برمجة في الواجهة أو السيرفر عند الضغط على زر Run.
